# Prompt Organizer

Веб-приложение для управления библиотекой AI-промптов. Работает полностью в браузере — без сервера, без зависимостей, данные хранятся в localStorage.

---

## Возможности

### Управление промптами
- Создание, редактирование, удаление и дублирование промптов
- Поддержка переменных в тексте: `{variable}` — перед копированием можно заполнить значения через специальный диалог
- Подсветка Markdown-синтаксиса в превью (жирный, курсив, код, заголовки, списки)
- Счётчик символов и приблизительный подсчёт токенов (1 токен ≈ 4 символа)
- Избранное, счётчик использований, время последнего использования
- Отмена удаления через уведомление (undo)

### Организация
- **Коллекции** — группировка по проекту или контексту (с цветовой маркировкой)
- **Категории** — классификация по типу (с цветовой маркировкой)
- **Теги** — произвольные метки, автодополнение при вводе
- Мультиселект фильтров: можно одновременно выбрать несколько коллекций, категорий и тегов

### Поиск и фильтрация
- Полнотекстовый поиск по названию, описанию, содержимому и тегам
- Быстрый доступ: все промпты, избранные, недавно использованные
- Фильтр-бар с активными фильтрами и кнопкой сброса

### Интерфейс
- Режимы отображения: сетка и список
- Три плотности интерфейса: compact, comfortable, spacious
- Светлая и тёмная тема
- Сортировка: по дате создания, алфавиту, популярности, дате использования
- Пагинация при более 50 промптах
- Адаптивный сайдбар (мобильная версия)
- Массовое выделение: удаление, перемещение в коллекцию, смена категории, избранное

### Импорт / Экспорт
- Экспорт в JSON (выбранные промпты или полный бэкап со всеми настройками)
- Экспорт в CSV (совместимость с Excel / Google Sheets)
- Импорт из JSON: режим слияния (дубликаты пропускаются) или замены
- Импорт из CSV с автоматическим созданием коллекций и категорий
- Валидация и санитизация данных при импорте

### Горячие клавиши
| Сочетание | Действие |
|-----------|----------|
| `Ctrl+K` | Поиск |
| `Ctrl+N` | Новый промпт |
| `Escape` | Закрыть модалку / очистить поиск |

## Архитектура

Приложение построено по паттерну **MVC** на ванильном JavaScript (ES6 модули).

```
Пользователь
    │
    ▼
[DOM Events] ──► [event-router.js] ──► [controllers/]
                                            │
                                            ▼
                                       [services/]  ◄──► [state.js]
                                            │                  │
                                            ▼                  ▼
                                        [models/]        [localStorage]
                                            │
                                            ▼
                                        [view/render.js]
                                            │
                                            ▼
                                          [DOM]
```

**Ключевые принципы:**
- **Единое состояние** — весь runtime-стейт в `state.js`, мутации только через `stateManager`
- **Event delegation** — один корневой обработчик, маршрутизация по `data-action`
- **Кэш с инвалидацией** — `getFilteredPrompts()` кэширует результат, сбрасывается при любом изменении через `stateVersion`
- **Lazy search index** — `_searchIndex` вычисляется геттером при первом обращении
- **Debounce** — сохранение в localStorage (1 с) и поиск (300 мс)

## Модель данных

### Prompt
```js
{
  id: string,            // UUID
  title: string,         // до 200 символов
  description: string,   // до 1000 символов
  content: string,       // до 50 000 символов
  collectionId: string|null,
  categoryId: string|null,
  tags: string[],        // до 50 тегов, каждый до 50 символов
  variables: string[],   // извлечены из {variable} в content
  favorite: boolean,
  usageCount: number,
  lastUsed: number|null, // timestamp
  createdAt: number,     // timestamp
  updatedAt: number      // timestamp
}
```

### Collection / Category
```js
{
  id: string,
  name: string,   // до 100 символов
  color: string,  // hex (#rrggbb)
  createdAt: number
}
```

## Хранилище

Все данные сохраняются в `localStorage` под ключом `promptOrganizerData`.

| Ключ | Содержимое |
|------|-----------|
| `promptOrganizerData` | Промпты, коллекции, категории, настройки, состояние сайдбара |
| `promptVariableValues` | Значения переменных по ID промпта (сохраняются между сессиями) |

Лимит: ~5 МБ. При достижении 80% выводится предупреждение в консоль; при превышении — диалог с предложением экспортировать данные.

## Запуск

Приложение не требует сборки или сервера. Достаточно открыть `index.html` в браузере.

> Для корректной работы ES6-модулей нужен локальный HTTP-сервер (CORS-ограничения браузера):

```bash
# Python
python3 -m http.server 8080

# Node.js
npx serve .
```

Затем открыть `http://localhost:8080`.

### Тесты

Открыть `http://localhost:8080/test.html` — результаты отображаются в браузере.
